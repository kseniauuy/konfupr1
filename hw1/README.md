# Домашнее задание №1 Вариант 29
___
## Описание
Этот проект представляет собой эмулятор командной оболочки, который позволяет взаимодействовать с виртуальной файловой системой (VFS), упакованной в архив .tar. С помощью этого эмулятора вы можете выполнять различные команды для управления файлами и директориями внутри VFS.
___
## Запуск программы

Чтобы запустить эмулятор, используйте следующую команду, указывая путь к вашему архиву VFS: `python main.py <vfs_path>
` Где <vfs_path> — это путь к вашему архиву .tar.

## Использование

ls — для отображения списка файлов в текущем каталоге архива.

cd some_directory — для перехода в указанную директорию.

cp file1.txt file2.txt — для копирования файла.

echo Hello, World! — для вывода сообщения в консоль.

exit — для выхода из эмулятора.
